# CLAUDE.md

Инструкции для Claude в этом репозитории.

## Что это

Боевая версия платформы WowSpeak (app.wowteach.ru): всё приложение — один
файл `index.html`. Идёт перенос на React в приватный репозиторий
`wowspeakschool-lang/wowspeak-platform`; основные правила, план и история
решений — в его `CLAUDE.md` и `MIGRATION.md`. Читать их перед работой.

## Главное

- **Это прод.** Любая правка — только по явному «да» владельца на
  конкретное изменение. Согласие на одну правку не распространяется на
  другую.
- **Репозиторий публичный.** Никаких секретов, ключей, адресов серверов и
  персональных данных — ни в коде, ни в коммитах. Значения секретов не
  показывать владельцу и в чате.
- **Код не удалять.** Ненужное — скрыть или отключить, оставив код и
  комментарий «почему, когда, по чьему решению».
- Баги, найденные по ходу, — записать и спросить, чинить ли; не чинить
  молча вместе с другой правкой.
- Правку в проде повторить в копии (`wowspeak-platform`), если она меняет
  поведение.

## Как править `index.html`

- Концы строк — **CRLF**. Править через Python:
  `io.open(path, encoding='utf-8', newline='')`, заменять строки с
  `\r\n`, записывать так же.
- После правки:
  1. одиночных `\n` (без `\r`) должно быть ноль;
  2. каждый инлайн-`<script>` (их 7) — через `node --check`.
- Комментарии — по-русски, объясняют «почему», с датой решения.
